## Leader = `Ctrl+A`
Lo pulsas, lo sueltas y tienes 1 s para pulsar la tecla. Mientras espera, aparece **● LEADER** a la izquierda de la barra.

### Paneles
| Atajo | Acción |
|---|---|
| `Leader` `\|` o `Leader` `v` | Dividir en dos lado a lado |
| `Leader` `-` o `Leader` `h` | Dividir en dos uno encima del otro |
| `Alt` + `h j k l` o flechas | Moverse entre paneles |
| `Leader` `r` y luego `h j k l` | Modo redimensionar continuo (sales con `Esc`/`Enter`, o solo tras 3 s) |
| `Leader` `Shift`+`H J K L` | Redimensionar un paso de 5 |
| `Leader` `z` | Zoom del panel (activar/quitar) |
| `Leader` `x` | Cerrar panel (pide confirmación) |
| `Leader` `o` | Rotar paneles |
| `Leader` `s` | Elegir panel por letra |

### Pestañas
| Atajo | Acción |
|---|---|
| `Leader` `t` | Nueva pestaña |
| `Leader` `n` / `Leader` `b` | Siguiente / anterior |
| `Alt` `1`…`9` | Ir a la pestaña N |
| `Leader` `,` | Renombrar pestaña |
| `Leader` `q` | Cerrar pestaña (pide confirmación) |

### Menús
| Atajo | Acción |
|---|---|
| `Ctrl+Shift+P` | Lanzador de shells: PowerShell, Git Bash, cmd y Git Bash sin perfil |
| `Leader` `p` | Paleta de comandos |
| `Leader` `w` | Espacios de trabajo |

### Copiar y buscar
| Atajo | Acción |
|---|---|
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | Copiar / pegar |
| `Leader` `f` | Buscar (sin distinguir mayúsculas) |
| `Leader` `[` | Modo copia (estilo vim) |
| `Leader` `Espacio` | QuickSelect: resalta URLs, hashes y rutas para copiarlos rápido |
| `Leader` `u` | Selector de caracteres y emoji (lo copia) |
| `Leader` `Ctrl+A` | Envía un `Ctrl+A` real al shell |

### Ventana y fuente
| Atajo | Acción |
|---|---|
| `Ctrl` `=` / `-` / `0` | Agrandar / achicar / restablecer la fuente |
| `Ctrl+Shift+K` | Borrar el historial de la terminal y la pantalla |
| `Ctrl+Shift+O` | Alternar entre transparente y opaco |
| `F11` | Pantalla completa |

### Ratón
- **Seleccionar** copia al portapapeles automáticamente.
- **Clic derecho** pega.
- **Ctrl+clic** abre enlaces. Un texto `"usuario/repo"` entre comillas también funciona como enlace y abre GitHub.

Dos detalles que noté al revisarla:
- El comentario de la línea 329 dice "mantén Leader y repite HJKL", pero el Leader se desactiva tras cada tecla. Para redimensionar varias veces seguidas usa `Leader` `r`.
- Como el Leader es `Ctrl+A`, en Git Bash ir al inicio de línea necesita `Ctrl+A` dos veces (`Leader` `Ctrl+A`), o la tecla `Inicio`.
